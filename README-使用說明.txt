宸胤建築師事務所｜現場勘查預約網站

GitHub Pages 上線方式
1. 將本 ZIP 解壓縮。
2. 登入 GitHub，建立一個新的 Repository（儲存庫）。
3. 點選 Add file → Upload files。
4. 上傳解壓後的所有檔案與 assets 資料夾；請勿只上傳 ZIP 本身。
5. 進入 Settings → Pages。
6. 在 Build and deployment 選擇 Deploy from a branch。
7. Branch 選 main，資料夾選 / (root)，按 Save。
8. 等待 GitHub 完成發布後，即可從 Pages 顯示的網址開啟網站。

預約送出方式
本版本適用於 GitHub Pages 靜態網站。客戶確認資料後，網站會開啟裝置的郵件程式，
並預先填好寄給 services@chenyin-arch.com.tw 的預約內容；客戶仍需在郵件程式按下寄出。

檔案說明
- index.html：網站主頁
- styles.css：網站外觀
- app.js：月曆、表單檢查與預約摘要
- assets/chen-yin-logo.jpg：事務所 LOGO

表單欄位包含申請人名稱、聯絡電話、申請地址、LINE ID、日期與預約時段。
